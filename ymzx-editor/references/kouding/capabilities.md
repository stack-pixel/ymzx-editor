# 扣叮支持范围

适用环境为Windows PC，前端资产需匹配[兼容指纹](compatibility.json)。安装器拒绝不匹配版本，不以版本文字相同代替文件哈希匹配。独立Lua见[Lua分类](../lua/workflow.md)，原生UI见[UI分类](../ui/workflow.md)。

| 能力 | 范围 |
|---|---|
| 工程读写 | 工程、积木定义、字段选项、基线比对、导入与读回 |
| 编译和运行 | 完整编译暂存、请求试玩、返回编辑器后读取日志 |
| 连接维护 | 状态查询、连接脚本更新、已暂存页面刷新及原文件恢复 |
| 工程恢复 | 从导入前备份恢复扣叮画布；不替代整图版本管理 |
| UI绑定 | Button、Text、Picture、ProgressBar、Group的真实UID与兼容类型检查 |
| 场景绑定 | 场景实例、信号触发盒、计数器与专属属性；实例变换另有冲突检查 |
| 资源查询 | 静态元数据、分类和分页、模板查询；查询结果不证明已创建对象 |
| 模组运行实例 | 模板引用与运行时创建、变换和销毁；不包含通用模板编辑器 |
| 实际输入 | 受游戏窗口约束的点击、键盘及短时按键；不包含通用寻路 |

命令和约束见[操作协议](operations.md)及[原生联动](native-editing.md)。接口适配依赖已支持的游戏资源，不是官方扩展协议；新控件、元件或积木类型按当前定义检查，不从基础类型推定全覆盖。

本包不提供MCP或远程网关、断点调试、实时日志推送、自动发布或多人协作管理。多人同步和云存档依项目分别验收，本地试玩不能替代这些验证。其他执行器需具备[连接条件](../connection.md)。
