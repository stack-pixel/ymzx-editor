# UI：原生布局与本地图片

处理原生按钮、文字、图片和布局；最终结果在元梦地图内可用。已有地图保留无关控件。需要保留现有交互时沿用原UID及点击绑定；独立新增行为使用新控件和真实新UID。

新建或重新设计UI时，依据项目指定的设备、方向和输入方式确定可用区域，见[目标设备与可用区域](responsive.md#目标设备与可用区域)。不默认固定画布或手机优先。

| 需求 | 读取 |
|---|---|
| 读取已有布局、调整位置/尺寸/分组 | [布局操作](layout.md) |
| 跨设备越界、图片变形、缩放与安全边距 | [布局适配与图片比例](responsive.md) |
| 本地图片上传、替换按钮、验证图片引用 | [本地图片](local-images.md) |
| 改点击行为、运行时样式或数据刷新 | [Lua分类](../lua/workflow.md)；用户选择积木时用 [扣叮分类](../kouding/workflow.md) |
| 更换执行AI或电脑 | [复用与交接](../reuse.md) |
| 接口与坐标点击、事件和状态断言 | [共用验收方案](../verification.md) |

本分类只接收本地文件；自己画的、设计软件导出的、网上下载的素材均可进入同一流程，不依赖特定创作工具。透明素材优先PNG。素材使用权限、格式支持和平台审核分别核对。

## 工具

```powershell
$env:YMZX_STATE_DIR='本次已有状态目录'
node '本技能目录/scripts/ui/run.mjs' native-ui-inspect roots 'UI_UGC_UIEditor_C_[0-9]+$' roots.json
node '本技能目录/scripts/ui/run.mjs' native-ui-document '实际地图目录/EditorMapDescription.des' '实际地图ID字符串' ui.json
```

`run.mjs`将工作目录设为状态目录并建立evidence，只运行本分类允许的工具。`node scripts/ui/run.mjs help`列出工具，包括`native-ui-control click/fill/drag`、`native-property-control`和`native-ui-call`；这些工具不依赖扣叮桥接。原生本机服务已实测127.0.0.1:30010；不存在时先恢复编辑器，不凭旧路径继续。

## 验证

先正常上传图片、在正确控件属性中选图、退出UI编辑器并正常保存地图，读回真实UID和素材引用。然后检查脚本是否在启动或周期刷新时覆盖底图、颜色、文字、位置与显隐；需要修改时进入相应脚本分类。最后试玩验证显示、透明边缘、文字、命中区域、点击面板和实际数据变化。

按[布局适配](responsive.md)检查不同宽高比、DPI和最小窗口下的最终渲染边界、弹窗子项及图片比例；离线几何通过与真实设备试玩分别记录。可用`ui-layout-audit`检查统一到客户区物理像素的矩形，但它不自动修正地图，也不证明点击有效。

默认以接口编辑和保存，再按[共用验收方案](../verification.md)读取动态坐标、发送实际点击并核对事件与状态，不依赖AI自带Computer Use。每次刷新对象、完整函数参数、目标类型、几何和可用状态。虚拟列表和属性行可能复用对象；显隐与非零几何不能排除遮挡。本分类使用随包Windows输入适配器，不使用缺省参数的引擎触控回调作为通用入口。不得只凭输入请求成功宣称完成。

Windows标准文件选择器使用随包`scripts/common/game-file-dialog-native.ps1`，支持受检查的图片多选提交；按[本地图片](local-images.md)传入实际PID与文件清单。结构不匹配时拒绝，不伪造选择回调。

`TriggerButtonClicked`只能传入已确认的真实UMG.Button；名称带btn或存在SetIsEnabled不证明类型，误传普通Widget可能导致客户端崩溃。参数或类型未核实则先补齐证据，不猜测调用；需界面输入时按共用方案确认适配器和目标。

超时先读现状，客户端恢复后重新枚举对象；不循环提交同一未知结果的写入。用户已授权的普通图片上传不重复询问，平台审核和资源登记照常执行。
