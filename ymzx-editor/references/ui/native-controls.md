# 原生操作键与默认 HUD 显隐

适用于隐藏前扑、托举、加速、跳跃等原生操作键，或自定义按钮与原生按键重叠。先确认用户要保留哪些能力与入口；不把某个项目隐藏的按键推广到所有地图。隐藏按钮、禁用角色能力、销毁控件是不同操作。

## 先选正确入口

| 需求 | 正常入口与边界 |
|---|---|
| 指定原生操作键开局不显示 | UI 编辑器选中真实原生控件 → 编辑/属性 → **游戏开始时为显示状态**关闭 → 退出 UI 编辑器正常打包 → 整图保存 → 重新试玩 |
| 原生表情、快捷聊天、拍照等类别运行时显隐 | 核对本机 `UI.d.lua` 的 `UI.UIType` 与 `UI:SetNativeInterfaceVisible`；只用当前枚举中存在的类别 |
| 自定义控件反复显隐 | 按真实 UID 使用 `UI:SetVisibility`；生命周期见[运行时实践](../lua/runtime.md) |
| 禁用跳跃/移动等能力 | 按任务查角色能力设置；这不自动证明按钮隐藏，不用它替代界面设置 |

SDK 没有某个按键的单独枚举，**不等于编辑器不能配置该按键**。检查 UI 编辑器的真实属性后再报告能力边界。画布“隐藏默认控件”等选项先核对作用范围，不能把作者视图中看不见直接解释为对局开局隐藏。

## 选中、切换与读回

- 用户已打开相关属性页时，从当前页开始读取；无需重走菜单。每次操作前重新核对控件名称与“游戏开始时为显示状态”标题。属性行会复用，同一路径可能已经表示另一项属性。
- 当前版本可见 `UI_UGCEditor_AdvanceSetting_UI_C_*` 的 `w_txt_Name` 与布尔属性行。名称是选中确认，UObject 后缀不是持久 UID；各地图的 UID 必须现场读回，不复制示例地图编号。
- 改开关用正常 `UMG.Button` 代理或实际输入。已验证的一种 `UI_UGC_SwitcherButton` 状态为索引 2 开、0 关；先核对本版语义，不把索引视为通用布尔协议。其他状态/结构拒绝套用。
- 可用 `native-ui-startup-visibility EXPECTED_NAME hidden|visible [OUT_JSON]` 修改**已经选中的**控件。它重新核对名称、标题与状态，点击后读回，不负责挑选控件、退出编辑器、保存或证明实机结果。命令从 `scripts/ui/run.mjs` 运行。
- 选另一个默认键时，右侧素材面板或属性面板可能覆盖目标，而旧几何仍非零。先关闭实际遮挡面板，再点当前模拟控件根；确认属性页名称确实改变后才修改。曾验证的素材面板入口为 `UI_UGCInterfaceEditing_Bag.w_btn_CloseBag`，每次仍检查真实路径、类型、可见性和几何。
- 管理列表用当次 `GetDisplayedEntryWidgets`；不能从全部池化行中选目标。SDK getter 白名单不包含某个原生只读方法时，可通过已核实完整签名的 `native-ui-call` 调用，不伪造不存在的 API。

## 验收实际效果

先记录并正常备份，再正常 UI 打包和保存。核对改动的原生记录，以及保留的自定义 UID、图片 ID、矩形和父子关系；原始记录哈希变化时，分别比较已解码字段，不把重存元数据变化误判为全部素材被改。

重新试玩检查实际按键消失、保留键可用及自定义按钮命中。某些原生技能槽隐藏后仍满足 `IsVisible=true`、保留旧尺寸，但 `GetRenderOpacity=0`；槽包装器存在不等于图标仍显示。反过来，透明为零也不能单独证明触摸不会被拦截；结合层级、命中与实际操作验证。

围绕跳跃键布局时，按**本次实际原生键矩形**定位自定义按钮，并保留用户要求的相对分布。需使用标定的右/下锚点时，记录其来源、比例范围及默认 HUD 配置，不能将单图常数当作任意设备或玩家自定义 HUD 的保证。

让有条件的按钮真实同时出现，例如正常拾取鱼/杂物、上岸靠近收集点，再检查全部按钮与跳跃键及彼此是否重叠，并分别点按验证。只检查空背包下唯一可见的按钮不够。宽高比、DPI 与真实手机边界见[布局适配](responsive.md)。
