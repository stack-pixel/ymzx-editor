# 独立Lua与原生UI运行时

从已安装的官方工程模板和SDK声明核对生命周期、事件、通知和TimerManager。客户端与服务端入口分别处理；快照早于UI初始化到达时，先暂存，完成绑定后刷新。

## 控件与初始化

通过地图真实UID绑定控件；Lua源码不替代原生布局文档。作者初始显隐与脚本运行时显隐分别检查。任务指定为模板的控件可在作者配置中关闭开局显示，运行时再创建或复制；业务控件是否开局可见由项目决定，不批量隐藏所有控件。

复制控件后检查父级显隐、控件透明度、图片透明度、层级和命中设置。运行时透明度可能叠乘作者配置；设置为完全不透明也不能恢复作者图片层为零的效果。使用当前版本SDK和实际显示核验，不能只读外层显隐。

原生属性、启动初始化和周期刷新各自可能修改布局、文字、图片及显隐。需要保留原交互绑定时沿用原UID；任务要求独立行为时为新控件取得新UID并绑定。周期刷新只更新必要数据，不重复初始化或累积缩放。

## 图片和布局

资源先经正常图库登记、绑定和保存依赖，再使用已核实的SDK方法，例如：

```lua
UI:SetImage({buttonUID}, resourceIdString, true)
UI:SetImageColor({buttonUID}, "#FFFFFFFF")
```

资源ID跨JSON、JavaScript和Lua保持字符串。检查启动样式或周期函数是否覆盖自定义图片。图片自带标题时避免叠加原生文字；独立文字便于本地化，按项目素材形式选择。

设计画布、作者坐标、运行时UI单位和物理像素分别记录。布局从原始设计值重算，按[布局适配](../ui/responsive.md)处理窗口变化；修改尺寸后同步依赖尺寸的进度填充等缓存。不要凭引擎习惯假设`SetRenderScale`的重置值或与Size的组合语义。

## 拖拽交互

先核对当前SDK回调参数及坐标系。起点与位移须转换到同一父容器坐标系；事件位移已经是UI单位时，不再乘屏幕/UI比例。按实际缩放换算，并用已知距离校准。

核对拖动期间与释放后的引擎位置行为；引擎会在释放时恢复位置的控件，应在释放回调提交最终位置。交互约束由项目逻辑决定。

## 服务端状态与存档

涉及服务端权威状态时，客户端提交动作，服务端核验身份、权限和参数后更新。身份取自可信通知来源；去重与状态更新按实际业务定义，旧客户端快照不能覆盖服务端状态。

按SDK要求序列化存档；需要字符串时使用已安装版本的`MiscService:Table2JsonStr/JsonStr2Table`。旧档解析失败保留原档，不能用空默认值覆盖。接口返回与跨局持久化分别验证。

## 核验

用本次会话与唯一构建标记筛选日志，分别验证初始化、实际交互、数据变化及保存重开。测试内容取决于项目行为，不沿用其他地图的控件数量、玩法断言或验收数据。
