# 换AI执行器、迁移与交接

交付完整ymzx-editor目录。支持SKILL.md的宿主按其目录规范安装；其他本地执行型AI先读SKILL.md，再读取分类和运行脚本。只发入口文档会缺少工具。

需要读取本地文件、运行Node.js22+/PowerShell、访问游戏主机回环服务和查看必要截图；无需宿主Computer Use/浏览器操控。Lua另需本机DreamHelper1.4.7。只有HTTP能力还需主机提供受控CLI入口，本包没有统一远程网关。未逐一实测所有AI和游戏版本。

同电脑沿用YMZX_STATE_DIR和已有监听器，串行写入。新电脑重新建立依赖，不复制令牌、旧路径/坐标或账户资源ID作为默认配置。标准游戏文件选择器由随包适配器处理；结构不匹配则拒绝并报告适配缺口，不宣称成功。

## 给另一个AI的任务模板

> 读取完整ymzx-editor技能，按需求选择UI、扣叮、Lua、元件分类。沿用当前工作区及连接，通过原生接口、本地CLI和随包Windows适配器执行，无需Computer Use。先核对本次地图、层与真实目标，正常保存读回。UI只接收现有本地图片，经正常上传/审核/登记/绑定取得真实资源ID。玩法使用用户选定的扣叮或独立Lua；明确不用扣叮时不启用其桥接。元件使用正式创建/复制和变换同步，运行时Spawn不算地图搭建。以同次运行的事件、状态和必要截图核验；明确记录本次完成的验证及工具覆盖范围。

交接信息包含实际工程/状态目录、地图/层、UID/实例ID、素材路径/用途/来源、脚本通道、期望行为、保存状态及验收位置。不把单张地图私有配置固化到技能。

## 提取已绑定图片映射

正常选图保存后，列出本次真实UID：

```json
{"controls":[{"key":"imageControl","uid":"本次真实UID","hasBakedCaption":false}]}
```

```text
node scripts/ui/run.mjs custom-image-bindings ABS_MAP_DES MAP_ID REQUEST_JSON OUT_JSON OUT_LUA
```

Lua输出可省略。工具只读作者数据并生成任务自己的JSON/Lua映射，不上传/绑定/保存。资源ID保持字符串；缺失/重复UID、内置图和预期ID不符会拒绝。新工程或账户先正常登记依赖，再导出映射。

只分享有权分享的代码素材。包内不带.local、日志、地图缓存、密码、令牌及官方插件/游戏资产，也不含图片创作流程、示例图或提示词。上传、保存、试玩、对外发布分别验收。
