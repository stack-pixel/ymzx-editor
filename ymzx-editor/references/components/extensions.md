# 扩展能力范围

本包提供正式场景元件的读取、创建、复制、变换和属性操作，详见[元件流程](workflow.md)。外部布局计划可在坐标标定后转换为基础元件摆放；图片可经正常登记用于UI或兼容的世界图片元件。

本包不提供通用技能图、粒子图作者器，也不提供任意FBX、GLB或OBJ的完整导入发布工具。发现内部函数名、打开面板或出现预览，均不构成这些制作能力。

涉及专用编辑器时，先确认当前版本、目标资源ID、完整参数和正常保存入口，仅处理任务指定部分。参数读回、保存重开、角色绑定、玩法触发和多人行为分别核验。超出随包工具覆盖范围时，说明具体缺少的操作入口，不承诺自动完成。

长时间轴条目需处理裁剪和实际渲染范围，见[共用验证](../verification.md)。零面积模板、禁用菜单和不可达的内部模块不可作为可操作入口。运行时创建对象不等于保存了编辑器资源。
